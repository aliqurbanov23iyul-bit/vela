# Demo bazar müşahidəsi

Yerli agent EURUSD və XAUUSD üçün MetaTrader5 `copy_rates_from_pos(symbol,timeframe,1,260)` ilə yalnız bağlanmış M5/H1 şamlarını və cari bid/ask qiymətini oxuyur. İlkin history hazır deyilsə növbəti dəqiqə yenidən sınayır. Broker suffix varsa həmin simvolun adı ayrıca saxlanır. Market HTTP işləri iki ayrı şəbəkə thread-indədir; bütün MT5 SDK çağırışları əsas thread-də qalır. Hesab snapshot-ları 15 saniyəlik dövrünü saxlayır; bazar məlumatı təxminən hər 60 saniyədə göndərilir. Yeni agenti işə salmaq lazımdır; köhnə çalışan proses fayl dəyişikliyini özü yükləmir.

`/api/agent/market` agent token hash-ını, tenant RLS-ni, broker login/serverini, DEMO hesab tipini və aktiv sahibi yoxlayır. Qiymət/OHLC, tarix sırası, interval, bağlanmış son şam, upload və quote freshness doğrulanır. Adi iş günündə çatışmayan şamlar AI-ni bloklayır. Yalnız həftəsonu boşluqları üçün konservativ UTC pəncərəsi (cümə 20:00–bazar ertəsi 02:00) qəbul edilir. Bu tam broker seans/tətil təqvimi deyil; bayram boşluqları bloklana bilər. Sintetik qiymət və şam yaradılmır; hesablamada yalnız mövcud qiymətlər istifadə olunur.

`market_latest` yalnız son bazar xülasəsini, `market_analysis_runs` AI cəhdlərinin nəticələrini tenant daxilində saxlayır. Bütöv raw şam tarixçəsi saxlanmır. Account row lock çağırış rezervini atomik edir. Default hər account/simvol üçün 30 dəqiqə cooldown və account üzrə UTC gündə 96 AI analiz cəhdi var. `AI_ANALYSIS_INTERVAL_MINUTES` (15–1440) və `AI_MAX_ANALYSES_PER_DAY` (0–288) ilə dəyişir. 96 analiz cəhdi, provider fallback olduğu üçün ən çox 288 provider HTTP çağırışı demək ola bilər; ayrıca pul büdcəsi deyil. Uğursuz cəhdlər də həddə daxildir. Eyni account/simvol/bağlanmış M5 şamı təkrar analiz olunmur. Serverless proses yarıda bitsə RUNNING qala bilər; cooldown-dan sonra yeni şam ayrıca cəhd yarada bilər. Paylanmış scheduler deyil: agent məlumat göndərdikcə axın işləyir.

AI-yə account ID, login, balans, token və şəxsi məlumat göndərilmir. Yalnız public market qiyməti, texniki göstəricilər, məhdudiyyətlər və random correlation ID-lər ötürülür. Provayder/model env-dən alınır. Nəticədə provider/model, müşahidə meyli, izah, mənbə və uğursuz provider səbəbləri saxlanır. AI-nin BUY/SELL meyli icra əmri deyil: server həmişə `action=NO_TRADE` saxlayır. Xəbər təqvimi, hesab risk profili, real broker risk/spec yoxlamaları və avtomatik əməliyyat mühərriki hazır deyil. Bu axın proposal, approval və order yaratmır; Telegram-a trade mesajı göndərmir.

Saytdakı AI analizləri bölməsi hər 10 saniyədə son məlumatı yoxlayır. Köhnə qiymət görünən şəkildə işarələnir; son AI müşahidəsi vaxtı ilə göstərilir, icazə kimi təqdim olunmur. AI açarı/model/quota problemi varsa NO_PROVIDER görünür. Bazanın 007 migration-ı production build-də tətbiq edilir.

Real MetaQuotes-Demo yoxlamasında broker epoch vaxtı UTC-dən +180 dəqiqə fərqli idi. Yalnız həmin lokal bağlantı faylında MT5_BROKER_UTC_OFFSET_MINUTES=180 saxlanır; ümumi default 0-dır. Agent bütün tick/şam vaxtlarından açıq konfiqurasiya olunan fərqi çıxır; köhnə ticki indiki vaxta çəkmir. Yay/qış saatı və broker dəyişəndə fərq yenidən yoxlanmalıdır. Qızıl tarixçəsində müşahidə edilən 20:00–22:00 UTC boşluğu yalnız MetaQuotes-Demo/+180 konfiqurasiyası üçün müşahidə hesablamasında qəbul edilir. Bu, təsdiqlənmiş broker sessiya təqvimi deyil və nəticədə BROKER_SESSION_CALENDAR_UNVERIFIED icra bloku saxlanır. Başqa saatlarda çatışmayan şamlar bloklanır.
